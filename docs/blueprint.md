# **App Name**: AgencyFlow

## Core Features:

- Home Page: Home page with agency overview, services, and client testimonials.
- Service Landing Pages: Dedicated landing pages detailing each service (Lead Generation, Performance Marketing, etc.).
- Contact/Booking Page: Contact page featuring a contact form, contact number (90789878654), and email (nikhileshswain5@gmail.com).
- Portfolio Showcase: Portfolio showcasing successful digital campaigns and projects.
- Blog/Insights Section: Blog/insights section to share industry expertise and agency updates.
- Case Study Generator: AI-powered tool to generate customized case studies for prospective clients, showcasing relevant agency capabilities.
- Animations of Portfolio: Show the past portfolios with animations

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) to convey expertise and sophistication.
- Background color: Very light gray (#F0F0F0), nearly white, for a clean and professional look.
- Accent color: Vibrant violet (#9400D3) to highlight calls to action and important information.
- Headline font: 'Playfair' (serif) for a sophisticated and elegant feel.
- Body text: 'PT Sans' (sans-serif) for readability and a modern look.
- Clean, professional icon set relevant to each service offered. Use line icons to convey sophistication.
- Clean and structured layout with ample whitespace for readability. Use a grid system for a consistent and professional look.
- Subtle animations on page transitions and hover effects to enhance user experience without being distracting. Use a tasteful, professional level of animation.
